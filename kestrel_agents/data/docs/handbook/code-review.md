## Approvals
Changes to services need two approvals before merging. Changes that only touch documentation need one approval.

## Response time
Reviewers should respond to a review request within one business day. If they cannot review in that time, they should say so and suggest another reviewer.

## What reviewers check
Reviewers check correctness, tests, readability and whether the change needs a migration or a feature flag. Style issues are left to the linter.
