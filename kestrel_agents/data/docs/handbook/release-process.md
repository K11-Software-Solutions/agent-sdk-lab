## Release train
Kestrel ships on a weekly release train that leaves every Tuesday. The code freeze for each train starts on Monday at 17:00 UTC.

## Hotfixes
A hotfix outside the train needs approval from the release manager on duty. Every hotfix must have a linked incident or bug ticket.

## Release notes
Release notes are drafted from the titles and labels of merged pull requests, then edited by the product manager before publication.
